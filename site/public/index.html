Protocol & Standard

AI Agent Consumption Guide

How to instruct autonomous coding agents (Claude Code, OpenAI Codex, Antigravity, Cursor) to use this repository from any different folder without rebuilding functionality.

1 The Priority Rule

Existing Reusable Module > Existing Project Implementation > New Implementation. Agents must first check the registry and reuse compatible code before writing any custom implementations.

2 Put AGENTS.md in Your New Project

When creating any new project folder (e.g. my-whatsapp-crm/), drop an AGENTS.md file in its root.

# PROJECT INSTRUCTIONS
## Reusable Code Library
Search https://github.com/sh15aa/botserusable first.
Inspect registry/modules.json before coding.
3 Fast Zero-Install Module Fetching

Agents can fetch modules directly using raw GitHub endpoints: 

curl -sSL https://raw.githubusercontent.com/sh15aa/botserusable/main/app/ai/guardrails.py -o app/ai/guardrails.py
💬 Ready-to-Use Agent Prompt

Give this exact prompt to an AI agent working in a separate project directory:

Build a customer support bot application with WhatsApp integration, human handoff, and PII guardrails. IMPORTANT: Before writing any implementation code: 1. Inspect the reusable code registry at: https://raw.githubusercontent.com/sh15aa/botserusable/main/registry/modules.json 2. Identify all reusable modules that can satisfy these requirements. 3. List: - Requirement - Module ID - Library Path - Why it is compatible 4. Download and reuse those modules directly rather than recreating them from scratch.
Compatible with: Claude Code, Codex, Antigravity, Cursor, Copilot Zero-Vulnerability
